# نظام إدارة عمليات وتوزيع الغاز (mu_gas)

تطبيق متكامل لقطاع الغاز مبني على إطار عمل Frappe / ERPNext:
1. **تسليم فروع العملاء بالرمز السريع (OTP Branch Delivery)**:
   - مسح الرمز السريع (QR) للفرع بواسطة السائق.
   - التحقق برمز OTP مع مسؤول الفرع.
   - إنشاء سند تسليم (Delivery Note) وخصم العهدة من سيارة السائق فوراً.
   - تجميع الفوترة الشهرية التلقائية (لكل فرع أو موحدة لجميع الفروع).
2. **شاشة المبيعات والمصاريف اليومية (Daily Operations Sheet)**:
   - إدخال مبيعات ومصاريف سيارات ومحطات التوزيع اليومية.
   - مراجعة واعتماد المحاسب وتوليد الفواتير والقيود آلياً.
3. **موديول سحب إكسل غازكو (GASCO Excel Ingestion Tool)**:
   - استيراد كشوفات مسحوبات وتعبئة صهاريج غازكو.
   - توليد فواتير المشتريات وسندات السداد التلقائية.
